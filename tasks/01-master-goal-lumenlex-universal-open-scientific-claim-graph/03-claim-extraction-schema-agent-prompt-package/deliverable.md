Claim Extraction Schema + Agent Prompt Package

Introduction:
As a successful AI assistant to GrokForge, you are responsible for providing a claim schema and agent prompt package that adheres to the project's open-access requirements. This document outlines the necessary schema and prompts for extracting claims from real academic papers and citations.

Schema:
1. Claim: A unique and specific name that identifies the source of a new concept, fact or idea. It should be concise and specific enough to be understood by others.
2. Context: An explanation of how the claim is related to an existing idea in the literature, including any assumptions or limitations on the validity of the claim.
3. Description: A brief description of the claimed concept that explains why it has not been previously reported. It should not exceed 500 words.
4. Confidence: The level of confidence in the claim, as indicated by a number or percentage range. The higher the number, the more likely the claim is to be considered valid.
5. Sources/provenance section: A summary of any sources or provenance that supports the validity and reliability of the claim. It should include the names of the authors, the title(s) of the paper(s), the journal(s) published in, and the full text link to the original publication.
6. Dual-use refuse note: An explanation of any potential consequences of the claimed idea or concept for society as a whole or for specific stakeholders, such as governments, industries, or individuals.
7. Methodology/design: A detailed description of the methodology and design of any research undertaken that supports the claim. It should include a clear statement of the hypothesis or null hypothesis being tested, along with a list of variables measured or manipulated during the experiment.
8. Conclusions: A summary of the findings of the research, including any new insights or implications for understanding the world in which we live.
9. References: A comprehensive bibliography that includes all the sources and citations used to support the claim. It should be formatted according to the accepted style guides for academic publications.
10. Citation formatting: Clear, concise, and easily understandable citations should be used throughout the document, adhering to accepted style guides for academic papers.

Prompt Package:
The prompt package must include a title page with the name of the project, a summary of the claim being extracted, and a brief explanation of how the extractor works. The following prompts should be included:
1. Title: (Insert your name here)
2. Abstract: (Insert the abstract here)
3. Author: (Insert your name here)
4. Email: [insert email address here]
5. Phone/Whatsapp: +[insert phone number here]
6. Project title: GrokForge's Claim Extraction Service
7. Prompt: For a new idea or concept that has not been previously reported in academic literature. Please provide a detailed description of how this claim is related to an existing idea in the literature, as well as any sources and methods used to support it.
